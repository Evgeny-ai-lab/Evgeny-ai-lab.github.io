QWEN KAGGLE / СВОЙ СЕРВЕР ЯЗЫКОВОЙ МОДЕЛИ

Свой ИИ-сервер на облачной видеокарте

Qwen с открытыми весами развёрнута в приватной сессии Kaggle. Собственный веб-чат и API позволяют задавать системные инструкции, управлять параметрами генерации и подключать модель к своим приложениям. Для работы не нужна мощная видеокарта на компьютере пользователя.

Исходники на GitHub ↗

01 / ЗАДАЧА

Управлять языковой моделью с обычного компьютера

Требовалась собственная среда для работы с языковой моделью: с управлением поведением, историей диалога и программным доступом. На ноутбуке нет подходящего GPU, поэтому вычисления перенесены на облачную видеокарту. Главная задача — связать запуск модели, удобный интерфейс и API в одном работающем решении.

04 / РЕЗУЛЬТАТ

Одна модель — чат для пользователя и API для приложений

Получена работающая среда с управляемыми настройками и потоковыми ответами. В реальном диалоге модель преобразовала заметки встречи в таблицу задач, исполнителей и сроков. Через API проверены обычный русский ответ и английская потоковая выдача. Запросы обрабатывает модель на Kaggle без обращения к коммерческому LLM API.

Проверка работоспособности

Проверены реальная генерация, завершение SSE-потока, отказ в доступе без ключа и отклонение некорректного параметра. Четыре теста разбора данных пройдены. После проверки GPU-сессия остановлена.
