QWEN KAGGLE / ОБЛАЧНЫЙ СЕРВЕР ЯЗЫКОВОЙ МОДЕЛИ

Qwen — языковая модель на облачной видеокарте

Qwen Kaggle — собственная среда для работы с большой языковой моделью (LLM). Модель запущена на видеокартах Kaggle, а пользователь обращается к ней через веб-чат или API. Вычисления выполняются на сервере: мощный компьютер не нужен, системные инструкции и параметры ответов можно задавать самостоятельно.

Рабочий проект · Проверен на облачном GPU

Исходники на GitHub ↗

01 / ЗАДАЧА

Запустить Qwen как самостоятельный облачный сервис

Требовалось развернуть языковую модель в собственной управляемой среде: с доступом через браузер и API, настройкой системных инструкций и параметров генерации. Обработка запросов должна выполняться на облачной видеокарте, независимо от мощности компьютера пользователя.

Главная задача — связать загрузку модели, сервер обработки запросов и удобный интерфейс. Это даёт возможность работать с Qwen с разных компьютеров и подключать её к другим приложениям без обращения к коммерческому LLM API.

04 / РЕЗУЛЬТАТ

Работающая Qwen с собственным чатом и API

Модель успешно запущена на облачных видеокартах и отвечает на запросы через оба интерфейса. В реальном диалоге Qwen преобразовала заметки встречи в таблицу задач; через API проверены обычный ответ на русском и потоковый ответ на английском.

Получена управляемая среда, в которой можно задавать инструкции и параметры генерации, использовать модель с разных компьютеров и интегрировать её в свои приложения. Обработка выполняется на сервере Kaggle без обращения к коммерческому LLM API.

Проверка работоспособности

Все четыре автоматических теста разбора данных пройдены. В реальной GPU-сессии проверены обычная генерация, потоковая передача текста и корректное завершение ответа, отказ в доступе без ключа и отклонение некорректного параметра.

Дополнительно проведена ручная проверка веб-чата на русском и английском: отправка запросов, получение ответов и работа интерфейса. На странице представлены реальные экраны и ответы модели. После проверки выделенная GPU-сессия завершена.
