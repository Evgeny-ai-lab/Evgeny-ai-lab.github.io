ОБЛАЧНЫЙ GPU-АПСКЕЙЛ / ОБРАБОТКА ИЗОБРАЖЕНИЙ

Качественный ИИ-апскейл без мощного компьютера

Несколько предобученных моделей апскейла адаптированы для самостоятельного запуска на облачной NVIDIA L4. Пользователь выбирает модель и настройки на своём MacBook или компьютере со слабой видеокартой, а тяжёлые вычисления выполняются удалённо. Клиент обрабатывает отдельные изображения или целую папку и сохраняет результаты локально.

01 / ЗАДАЧА

Получить качественный апскейл на слабом компьютере

Требовалось использовать нейросетевой апскейл без мощной локальной видеокарты и ручной обработки каждого файла в графическом приложении. Задача — разобраться во входах нескольких готовых моделей, воспроизвести необходимые параметры обработки и собрать самостоятельный облачный сервис. Пакетный запуск должен был сделать этот процесс удобным для работы с сериями изображений.

04 / РЕЗУЛЬТАТ

Из 1536 × 640 в 6144 × 2560 — реальный результат 4×

Облачный запуск моделью CGI / Art 4× завершился получением 16-битного PNG размером 6144 × 2560. Изображение увеличено в четыре раза по каждой стороне. Ниже можно сравнить одинаковые фрагменты исходника и результата; клиент позволяет повторить обработку для серии файлов.

Проверка работоспособности

В контрольном запуске обработаны 55 тайлов. Инференс занял 6,25 секунды, удалённый вызов до получения файла — 113,29 секунды, включая подготовку обработчика и передачу результата. Это измерение одного запуска, а не обещание скорости для всех изображений.
