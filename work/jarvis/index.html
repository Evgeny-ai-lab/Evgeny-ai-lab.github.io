JARVIS / МУЛЬТИМОДАЛЬНЫЙ ИИ-АССИСТЕНТ ДЛЯ MAC

Голосовой ИИ-ассистент, который не только отвечает, но и действует

JARVIS — персональный ИИ-ассистент для macOS, объединяющий голосовое общение, управление компьютером, компьютерное зрение и автономных ИИ-агентов. Он может вести обычный диалог, работать с приложениями, искать информацию, анализировать документы, писать код и выполнять сложные задачи по голосовой или текстовой команде.

Голосовое взаимодействие, системная автоматизация и выполнение агентных задач объединены в единую систему. Долговременная память, библиотека навыков и автоматизация позволяют использовать JARVIS не только как собеседника, но и как постоянного помощника в повседневной работе.

Работающее приложение для macOS · 128 автоматических тестов

01 / ЗАДАЧА

Управлять компьютером и решать задачи обычным разговором

Цель проекта — создать универсального персонального ИИ-ассистента, с которым можно взаимодействовать так же естественно, как с человеком: разговаривать голосом, задавать вопросы, показывать предметы через камеру, обсуждать содержимое экрана и поручать выполнение задач.

При этом ассистент должен не ограничиваться ответами. Он должен уметь самостоятельно взаимодействовать с macOS, управлять приложениями и браузерами, работать с файлами, выполнять автоматизацию и подключать специализированных ИИ-агентов для более сложной работы — от исследования информации до разработки и проверки программного кода.

Важная часть задачи — объединить все эти возможности в одном приложении, сохранив удобный голосовой интерфейс, контекст общения, память и возможность продолжать разговор во время выполнения фоновых заданий.

02 / ВОЗМОЖНОСТИ

От голосовой команды до выполненной задачи

Естественное голосовое общение

JARVIS поддерживает двусторонний голосовой диалог в реальном времени. Его можно активировать голосовой фразой, разговаривать без постоянного нажатия кнопок, перебивать во время ответа и переключаться между голосом и текстом.

Система распознаёт речь, воспроизводит ответы и позволяет продолжать общение, пока другие агенты выполняют порученные задачи.

Управление компьютером голосом

Ассистент взаимодействует с интерфейсом macOS: открывает приложения, переключает окна, нажимает кнопки, вводит текст, прокручивает страницы и использует сочетания клавиш.

Поддерживается управление Safari, Google Chrome и другими приложениями через системные механизмы macOS. Доступен также встроенный браузер для самостоятельной работы с веб-страницами.

Компьютерное зрение и камера

JARVIS может получать изображение с экрана, анализировать отдельные окна и выделенные области, распознавать текст, интерфейсы и визуальные элементы.

Веб-камера позволяет показывать ассистенту предметы, документы и окружающие объекты, задавать вопросы об увиденном и использовать распознавание жестов для отдельных сценариев управления.

Сложные задачи, исследования и программирование

Помимо голосового диалога и непосредственного управления компьютером, JARVIS может передавать задания подключённой агентной системе. Это позволяет выполнять многоэтапные операции: исследовать информацию, работать с файлами и проектами, создавать и редактировать программный код, запускать команды, тесты и другие инструменты.

Пользователь ставит задачу голосом или текстом, а выполнение передаётся агентному механизму. Результаты возвращаются в общий интерфейс ассистента.

Четыре специализированных ИИ-агента

В систему интегрированы четыре исполнителя с отдельными ролями:

  • Архитектор-разработчик — программирование, создание проектов, исправление ошибок и тестирование.
  • Аналитик-исследователь — поиск информации, исследования, сравнение решений и аналитика.
  • Рецензент-тестировщик — проверка кода, выявление проблем и аудит решений.
  • Технический писатель — подготовка документации, инструкций и структурированных материалов.

У каждого агента собственные инструкции, память и область ответственности. Задания распределяются через общий механизм управления задачами.

Параллельная работа агентов

Ассистент способен организовывать несколько заданий, распределять их по приоритетам, отслеживать состояние исполнителей и управлять очередью.

Длительные операции выполняются отдельно от голосового интерфейса. Это позволяет продолжать разговор с JARVIS, пока специализированный агент работает над поставленной задачей.

Библиотека навыков

JARVIS может осваивать новые сценарии автоматизации. После выполнения незнакомой операции пользователь подтверждает её успешность, и проверенная последовательность действий сохраняется как отдельный навык.

В дальнейшем такую операцию можно запускать повторно по голосовой команде, без необходимости каждый раз заново подбирать способ выполнения. Навыки доступны для поиска, ручного создания, проверки и удаления.

Долговременная память и Obsidian

Ассистент сохраняет полезную информацию, заметки, знания о проектах и ранее освоенные сценарии. Для долговременного хранения используется интеграция с Obsidian.

Память специализированных агентов разделена, а информация организована в Markdown-заметках с тегами и связями. Это позволяет возвращаться к предыдущим задачам и использовать сохранённый контекст в дальнейшей работе.

Голосовая диктовка в приложения

JARVIS позволяет диктовать текст и вставлять его непосредственно в Telegram, заметки, Pages, Word, VS Code, Safari и другие приложения macOS.

Реализованы выбор целевого окна, подготовка текста, копирование в буфер обмена, повторная вставка и история диктовки.

Напоминания и автоматизация по расписанию

Ассистент понимает команды на естественном языке для создания напоминаний и фоновых заданий.

Можно назначать одноразовые события, повторяющиеся действия и автоматические сценарии по расписанию. Планировщик поддерживает интервалы, указанное время и Cron-выражения.

Полноразмерный интерфейс и плавающая капсула

JARVIS работает как полноценное настольное приложение с отдельными разделами для агентов, навыков, памяти, расписания и системных инструментов.

Для быстрого взаимодействия доступна компактная плавающая капсула поверх других окон. Она показывает состояние ассистента и позволяет управлять голосовым взаимодействием, не открывая основной интерфейс.

03 / ИНЖЕНЕРИЯ

Как устроена система

Разделение голосового интерфейса и интеллектуального ядра

Архитектура JARVIS разделяет голосовое взаимодействие и непосредственное выполнение задач.

Gemini Live обеспечивает потоковый голосовой диалог, а для сложных операций используется отдельная агентная среда, установленная на компьютере. Она предоставляет инструменты для работы с кодом, файлами, терминалом и другими ресурсами. Брокер задач связывает эти компоненты, управляет запущенными процессами, очередями и передачей результатов.

Благодаря такому разделению длительная работа агента не должна блокировать голосовой интерфейс.

Голосовое взаимодействие на бесплатных API-ключах

В текущей конфигурации голосовой контур использует бесплатные API-ключи Gemini. Агентные задачи обрабатываются отдельно, через установленную на компьютере среду, авторизованную с помощью аккаунта Google.

Реализован механизм резервных подключений: при ошибках соединения или достижении доступных квот система переключается между заранее настроенными ключами.

Для ожидания команды активации используется отдельный механизм обнаружения речи, поэтому постоянная открытая голосовая сессия не требуется.

Нативная интеграция с macOS

Для управления компьютером применяются системные средства Accessibility, AppleScript и механизмы ввода macOS.

Ассистент может находить элементы интерфейса по их свойствам, взаимодействовать с кнопками и полями, отправлять события клавиатуры и мыши.

Нативные компоненты на Swift и C++ обеспечивают взаимодействие между приложением и системными интерфейсами macOS.

Обработка визуальной информации

Система поддерживает получение изображения с экрана и камеры, захват отдельных окон и интерактивное выделение произвольной области поверх других приложений.

Визуальный контекст передаётся на анализ по запросу. Для захвата экрана предусмотрены обработка состояния сессии, исключение устаревших кадров и очистка временных изображений.

Автоматизация и повторное использование навыков

Для новых операций JARVIS может подбирать последовательность системных действий, а после подтверждения результата сохранять её как исполняемый сценарий.

При повторном запросе система обращается к библиотеке готовых навыков вместо повторного поиска решения. Такой механизм позволяет расширять возможности автоматизации без переобучения самой языковой модели.

Безопасность выполнения действий

Обычные операции автоматизации и потенциально опасные действия обрабатываются по разным правилам.

Удаление данных, изменение критичных настроек и другие рискованные операции требуют дополнительного подтверждения. Сохранённые навыки проходят проверку на запрещённые команды.

Эти механизмы снижают риск нежелательных действий, но не заменяют системные ограничения доступа macOS.

Память и организация данных

Локальное состояние приложения хранится отдельно от долговременных знаний. Интеграция с Obsidian обеспечивает хранение заметок, навыков и информации о проектах в читаемом Markdown-формате.

Для специализированных исполнителей используются отдельные области памяти. Дополнительно предусмотрено построение карт проектов с информацией об используемых технологиях и структуре рабочих папок.

Управление процессами и состоянием приложения

Внутренняя система управляет параллельными агентными заданиями, приоритетами, отменой операций и обработкой ошибок.

Отдельно реализованы восстановление голосовых подключений, контроль жизненного цикла аудио, переключение между основным окном и капсулой, а также взаимодействие между интерфейсом и фоновыми процессами.

Сборка и системные разрешения

JARVIS разработан для macOS на Apple Silicon и включает нативные системные компоненты.

Для стабильной работы реализована последовательная подпись внутренних библиотек, вспомогательных процессов и основного приложения. Учитываются системные разрешения на микрофон, камеру, захват экрана и управление компьютером.

04 / ИНТЕРФЕЙС

Инструменты для повседневной работы

В JARVIS основные возможности вынесены в отдельные разделы, доступные из главного окна. Пользователь может управлять агентами, создавать автоматизации, работать с памятью, диктовать текст и настраивать взаимодействие с компьютером.

На скриншотах представлен реальный интерфейс приложения. Для демонстрации отдельных функций использованы тестовые заметки, навыки и задания.

05 / РЕЗУЛЬТАТ

Персональный ИИ-ассистент с голосовым управлением и автономными агентами

Разработано настольное приложение для macOS, объединяющее возможности разговорного ИИ, компьютерного зрения, системной автоматизации и специализированных агентов в одном интерфейсе.

JARVIS позволяет не только получать ответы, но и переходить от обычного голосового запроса к выполнению действий на компьютере: работе с приложениями, обработке информации, исследованию задач, созданию файлов и программного кода.

Реализованы долговременная память, сохранение навыков, планировщик, голосовая диктовка и параллельное выполнение агентных заданий. Приложение можно использовать в основном окне или в виде компактной плавающей капсулы.

Проверка работоспособности

Для проверки основных компонентов проекта реализован набор из 128 автоматизированных тестов. Проверяются голосовые состояния, механизмы управления задачами, резервные подключения, сохранение навыков и памяти, работа планировщика, диктовка, браузерная автоматизация и элементы интерфейса.

Дополнительно проводилось ручное тестирование приложения: проверялись отдельные пользовательские сценарии, работа интерфейса, создание и выполнение навыков, сохранение заметок, напоминания и переключение между режимами отображения.

Представленные скриншоты получены из работающего приложения с демонстрационными данными. Они показывают интерфейс и отдельные проверенные сценарии, но не заменяют полноценное интеграционное тестирование всех функций с внешними ИИ-сервисами.

06 / ТЕХНОЛОГИИ

Технологии и их назначение

Electron 41

Основа настольного приложения для macOS: главное окно, компактная капсула, интерфейс, системная интеграция и управление жизненным циклом приложения.

Node.js 22

Серверная логика внутри настольного приложения: брокер агентных заданий, фоновые процессы, управление состоянием, локальные данные и взаимодействие с системными инструментами.

JavaScript · HTML · CSS

Реализация интерфейса, пользовательских сценариев, управления вкладками, интерактивных элементов и визуальных состояний.

SVG · Canvas

Анимация центрального индикатора JARVIS, визуализация состояний голосового интерфейса и графические элементы приложения.

Google Gemini Live API

Двустороннее голосовое взаимодействие в реальном времени, обработка и воспроизведение речи, поддержка перебивания ассистента во время ответа.

Gemini Flash-Lite

Проверка голосовой команды активации после обнаружения речи в режиме ожидания.

Google Antigravity

Подключённая агентная платформа для выполнения сложных заданий. Используется через установленную на компьютере среду для работы с программным кодом, файлами, терминалом и другими инструментами.

WebSocket · PCM Audio

Двусторонняя потоковая передача аудиоданных и поддержка голосовых сессий с низкой задержкой.

Web Audio API · VAD

Обработка звука, определение речевой активности, управление микрофоном и механизм голосового пробуждения.

Swift · C++ · Node-API

Нативные компоненты для взаимодействия Node.js с системными возможностями macOS.

macOS Accessibility API

Получение структуры интерфейсов приложений, обнаружение элементов и выполнение действий с кнопками, окнами и текстовыми полями.

AppleScript · Bash

Системная автоматизация, запуск команд и создание повторно используемых сценариев управления компьютером.

Quartz · CGEvent

Эмуляция событий клавиатуры и мыши, сочетаний клавиш, нажатий и других действий в macOS.

ScreenCaptureKit

Захват экрана и окон приложений для визуального анализа.

Electron WebContentsView

Встроенный браузер с отдельным профилем и средствами взаимодействия с веб-страницами.

Obsidian · Markdown · YAML

Долговременная память, заметки, библиотека навыков, структура знаний, карточки проектов и сохранение контекста специализированных агентов.

JSON

Локальное хранение конфигурации, настроек и состояния отдельных подсистем приложения.

Cron · Task Scheduler

Планирование напоминаний, периодических задач и автоматического выполнения фоновых сценариев.

Electron IPC · Context Isolation

Защищённый обмен сообщениями между интерфейсом и основным процессом приложения, разграничение доступа к системным функциям.

macOS TCC · Codesigning · Entitlements

Управление системными разрешениями и корректная сборка и подпись приложения вместе с нативными библиотеками и вспомогательными процессами.

Node.js Test Runner (node)

Автоматизированное тестирование основной логики приложения, агентных процессов, памяти, автоматизации, голосовых состояний и системных механизмов.
